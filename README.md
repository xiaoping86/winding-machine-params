# 绕线机参数设置 / 机卡参数

HBuilder X 可打包的 HTML5+ 安卓应用：绕线机（定子）参数管理、查询、导入导出、样品图片。

## 功能

- 型号参数保存 / 查询 / 列表载入
- CSV 参数导入导出（兼容 Excel）
- 样品图片：选图预览，点「保存」写入 `Download/样品图片/型号名.jpg`
- 主题：经典工业 / iOS 扁平
- 界面疏密度、字体大小（持久化）
- 权限：
  - 普通：仅查询、显示已保存
  - 管理员：全部功能（默认密码见下方）
  - 超级管理员：可修改普通管理员密码

## 使用方式

### 浏览器

直接打开 `index.html`。

### HBuilder X 打包安卓

1. 新建 5+ App 项目，将本仓库文件放入项目根目录
2. 确认 `manifest.json` 中 `launch_path` 为 `index.html`
3. 配置存储相关权限后云打包或真机运行

入口文件请使用小写 **`index.html`**（避免部分打包环境大小写问题）。
